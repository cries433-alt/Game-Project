Pong Arena - B37VB Game Project Submission

Files included:
- pong_game.c          Main C source code for the game
- B37VB Praxis Programming Report Joseph Adeboye.docx     Assignment report

How to compile:
- Windows (MinGW): gcc -std=c11 pong_game.c -o pong_game.exe

How to run:
- Windows: pong_game.exe

Controls:
- W = move up
- S = move down
- P = pause/resume
- R = restart current match
- K = save game
- Q = return to main menu

Save file:
- The game creates pong_save.txt in the same folder when you save.
